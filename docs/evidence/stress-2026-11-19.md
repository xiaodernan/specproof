## 撞库场景结论（20 s · 25 VUs · 随机伪造 key）

- **8,276 次随机伪造 X-API-Key → 0 次成功 · 0 个 2xx · 0 个 500**
- 全部被 `require_api_key` 在比较前挡掉（`hmac.compare_digest` 常数时间）；平均 **7 ms/请求**，CPU 余量充足，没出现锁集风暴
- 认证语义：未认证流量**先撞 401 墙，再轮不到 rate limiter**——刻意的顺序，不向攻击者泄露 limiter 存在
- 诚实小否:不给生产注入 "撞库后立刻锁" 的假写 —— 锁的是人,不是假 key；这台单 tenant 部署的最佳 DoS 防线本来就不靠账户锁

## 最终目标（一句话）

造出一个**无穷观的世界**：来者不惑、深思不迷——每一页里都有能找到的东西、能信的证据、能留下的印；
用户感到这个世界无穷大，所有入口都通向下一扇门；而一切"看见的人"都是经由证据论证得出的，不是幻觉。

## 性质与纪律

- **集大成**：收益优先于新颖；
- **保质保量**：每一块交付都要有测试锚点 + 账本条目 + chronicle 节数；
- **双语对称**：zh/en 逐表对齐，其余语言尚未承诺；
- **诚实**：不全绿不说全绿，不上线不说上线；数字可复现、可 git show；
- **隐私**：零真实用户 PII；合成校准必须标注；真实遥测要隐私评审签字；
- **人口**：门禁不会因开发压力而关闭；gate 红了就是红了，不改断言。

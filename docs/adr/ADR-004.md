# ADR-004 — 为什么高等级 Finding 必须带可执行证据

状态: 已接受 (2026-08)

背景: 静态正则只能证明"看起来像问题", 差分执行才能证明"问题由这个
PR 引入"; 没有可重放证据的高等级结论只是模型判断, 无法审计。

决策: BLOCKER 必须同时满足 6 个条件 (agent/nodes/review_court.py
_check_blocker_conditions):
1. 已批准 Contract 存在 (approved);
2. 真实 Base/Head 执行 (两个方向都记录了 exit code);
3. 归因到 Head (base_pass_head_fail / differential_execution);
4. DB/行为证据 (如 DB_MUTATED_ON_UNAUTH 状态取证);
5. Capsule 可重放 (证据被打包进 capsule);
6. confidence ≥ 0.90。
静态分析类发现封顶 MAJOR (run_static_checks.py 的
_STATIC_CONFIDENCE_CEILING = 0.85), 无论置信度多高都不能越过
"没有执行证据"这条线。

理由: 可重放性把结论从模型判断变成事实陈述; 六条件逐条检查让
"证据充分"可机器判定, 也让审计可以逐条复核。

后果: 检测管道必须真实执行测试; 没有执行能力的结论自动降级;
旗舰案例实测 (base→head-v1) 输出 1 个满足全部六条件的 BLOCKER
(capsule-COURT-AUTH-01 的 blocker_check 记录了 6/6 true)。

对应 PRODUCTION_SPEC: §22 ADR-004; §14 SLO (无证据严重评论 = 0)。
